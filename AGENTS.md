# Agent entry point

**Read, in this order, before any work:**

1. `CLAUDE.md` — the developer guide (architecture, schemes, conventions,
   data-quality rules). Treat it as this repo's canonical agent instructions;
   the filename is historical.
2. `ONBOARDING.md` — tenets, the scheme-addition loop, publish order, landmines.
3. `HANDOFF.md` — where the last session left off and what's next.
4. The logbook trio: last ~20 entries of `tasks.md`, all of `findings.md`,
   all of `learnings.md`. Every painful rule in `learnings.md` was paid for —
   they are laws, not suggestions.

Log your own work to the trio as you go (format at the top of each file).
Frontend conventions live in `web/AGENTS.md`.
